# Unified Catalog & Taxonomy System

The platform uses a **Unified Taxonomy** stored in the `categories` table. This simplifies the architecture by treating Navigation Menus (Catalog) and Product Filters (Attributes) as the same entity type, differentiated only by a flag.

## 1. The `categories` Table Structure

| Column | Type | Description |
| :--- | :--- | :--- |
| `type` | Enum | **`catalog`** (Navigation) or **`attribute`** (Filter). |
| `parent_id`| BigInt | Hierarchical nesting (e.g., Men -> Shirts). |
| `display_style` | Text | 'list' (Checkbox), 'swatch' (Color), 'pill' (Size). |
| `embedding` | Vector(768) | Generated by AI for semantic matching. |
| `start_date` | Timestamp | Auto-show category after this date. |
| `end_date` | Timestamp | Auto-hide category after this date. |

## 2. Catalog Categories (Navigation)
* **Usage**: Main Menu, Breadcrumbs, URL Routing (`/categories/[slug]`).
* **Example**: "Men", "Summer Collection", "Accessories".
* **Logic**: A product is linked to these via `product_categories`.

## 3. Attribute Categories (Filters)
* **Usage**: Sidebar Filters, Variant Definitions, AI Search.
* **Example**:
  * Group: "Color" (Parent)
  * Value: "Red" (Child, linked to Variant).
* **Logic**:
  * Linked to **Product Variants** via `variant_attributes` table.
  * This allows granular filtering (e.g., filtering for "Red" shows products where the *Red variant* exists).

## 4. Semantic Search Integration
Both `categories` and `collections` tables have an `embedding` column.
* **Vector Setup**: `vector-setup.sql` defines the `ivfflat` index.
* **Matching**: The `match_categories` and `match_collections` RPC functions compare user input vectors against these table vectors to find relevant filters even if the keywords don't match exactly.

## 5. Time-Fencing
Categories can be scheduled. The API (`app/api/categories/route.js`) automatically filters out categories where:
* `start_date` > NOW
* `end_date` < NOW

This enables "Flash Sale" categories or "Seasonal" collections that appear and disappear automatically.
